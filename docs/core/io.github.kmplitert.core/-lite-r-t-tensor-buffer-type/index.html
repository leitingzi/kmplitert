LiteRTTensorBufferType

enum LiteRTTensorBufferType : Enum<LiteRTTensorBufferType>

Represents the underlying storage type used by a tensor buffer.

Different buffer types correspond to different hardware backends or memory representations, allowing LiteRT to perform inference with minimal data copying.
