# 在线示例

选择内置温度模型，或加载本地 `.tflite` 文件。对于自定义模型，输入模型的输入和输出张量名称以读取类型与形状，然后填写逗号分隔的数据并运行推理。当前示例支持单输入张量、单输出张量的模型。
